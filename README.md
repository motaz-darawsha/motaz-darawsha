## What I work on

- **Discord music bots** — playback events, queues, canvas cards
- **APIs** — Express / Nest, clear routes, predictable errors
- **State** — Redis for hot data, Mongo or Postgres for durable store

Card events I design for:

| Type | Progress bar | Shows |
|------|--------------|--------|
| `nowPlaying` | yes | times, volume |
| `startSong` | no | started state |
| `addSong` | no | queue position, metadata |

## Approach

- One job per module
- Failures visible in logs, not silent
- Prefer boring, readable code over clever tricks
